# Homelab
Unbuntu Server

My first home lab project using Ubuntu Server.

## Server Hardware

- **Manufacturer:** HP
- **Model:** HP Laptop 15-dy1xxx
- **CPU architecture:** x86-64
- **RAM:** 16 GB
- **Storage:** 230 GB available to Ubuntu
- **Network:** Realtek RTL8723DE Wi-Fi adapter
- **Operating System:** Ubuntu Server 26.04 LTS

## Why Ubuntu Server?

I chose Ubuntu Server because it is widely used in professional Linux, cloud, networking, and DevOps environments.

This project will be used as a learning environment to practice:

- Linux system administration
- Networking
- SSH
- Docker
- Git and GitHub
- Server configuration and troubleshooting

## Initial Setup

The first mission was to install Ubuntu Server and verify that the basic system was working correctly.

The following requirements were successfully completed:

- Ubuntu Server boots successfully
- Administrative account works
- Hostname is configured
- Network connectivity works
- Network configuration survives a reboot

The server is currently connected to the home network through Wi-Fi.
